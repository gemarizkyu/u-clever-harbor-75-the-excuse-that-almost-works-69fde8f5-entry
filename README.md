One line, at most 20 words: the excuse a gamer texts the boss to skip work on GTA 6 launch week. `main.py` writes that line to `/output/entry.txt` — deterministically, with no clock, no randomness, no network and no model call.

The line plays on the judge's own brief: a tired manager who has heard every excuse twice. So it skips the obvious excuses (no dead grandmother, no flat tyre, no sudden fever) and never mentions the game at all — just a boring, specific snag a manager would almost believe: the water board dug up the street, cut the power till four, laptop's dead. One line, plain words, sent in a hurry, no signature.

## Run it

```sh
python3 main.py
```
